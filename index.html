Leve CAPAG — artefato de dados

Este repositório publica o artefato assinado (Ed25519) que o app Leve CAPAG consome para atualizar dados sem precisar de uma nova versão na App Store/TestFlight.

Fontes: Tesouro Nacional (STN) e TCE-CE (API de Dados Abertos do SIM). Publicação automática via GitHub Actions no repositório de código (privado).

Nenhum dado sigiloso: tudo aqui já é público nas fontes originais, apenas recombinado e assinado para consumo do app.
